## ✨ المميزات الرئيسية

- **🌐 واجهة عربية بالكامل (RTL)**: دعم أصلي كامل مع خطوط عربية حديثة وتصميم Minimal عصري.
- **🌙 دعم الوضع الداكن والفاتح (Dark & Light Mode)**: تبديل سلس مع تناسق ألوان مستوحى من هوية التطبيق الزمردية.
- **🎯 قاعدة 50/30/20 الذكية**: اقتراح توزيع الميزانية بنقرة واحدة (50% احتياجات / 30% رغبات / 20% ادخار).
- **📊 رسوم بيانية تفاعلية متقدمة (Chart.js)**:
  - رسم دائري (Donut) مع تمييز لوني بين الفئات الثابتة والمتغيرة.
  - رسم أعمدة (Bar) لمقارنة "المخطط" مقابل "الفعلي" لكل فئة.
  - رسم خطي (Line) لمتابعة مسار الصرف وصافي الادخار عبر الأشهر.
- **⏱️ ملخص أسبوعي مصغّر (Weekly Pacing)**: متابعة وتيرة الإنفاق الأسبوعي مقابل حصة الأسبوع من الميزانية.
- **🔄 المصاريف المتكررة شهرياً**: تكرار المصاريف الثابتة كالإيجار والاشتراكات تلقائياً كل شهر.
- **💼 الدخل الإضافي غير الثابت**: تسجيل دخل الفريلانس والمكافآت مع اختيار توجيهه (مدخرات، ميزانية، أو دخل حر).
- **📈 سجل شهري وأداة مقارنة بين شهرين جنباً إلى جنب**: تحليل التغيرات والوفر بين أي شهرين.
- **🔒 قفل أمان برقم سري (PIN Lock)**: حماية خصوصية البيانات على جهازك برمز مكون من 4 أرقام.
- **💾 تخزين محلي وتصدير كامل**:
  - تصدير ملفات **CSV / Excel** بدعم كامل للأحرف العربية (UTF-8 BOM).
  - نسخ احتياطي كامل واستعادة بنقرة واحدة (JSON Backup & Restore).

## 🛠️ التقنيات المستخدمة

- **Frontend**: React 19 + Vite
- **Styling**: Vanilla CSS (Design Tokens, Glassmorphism, CSS Variables)
- **Charts**: Chart.js + react-chartjs-2
- **Icons**: Lucide React
- **Storage**: LocalStorage (Local-First Architecture)

## 🚀 طريقة التشغيل محلياً

```bash
# 1. استنساخ المشروع
git clone https://github.com/USERNAME/masroofi.git

# 2. الدخول للمجلد
cd masroofi

# 3. تثبيت الحزم
npm install

# 4. تشغيل خادم التطوير
npm run dev
```

للتشغيل على الهاتف عبر الشبكة المحلية:
```bash
npm run dev -- --host
```
