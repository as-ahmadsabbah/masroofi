## ✨ المميزات الرئيسية

- **☀️ شاشة اليوم المباشرة**:
  - أول ما يظهر عند فتح التطبيق: **"صرفت اليوم: X ₪"** بخط كبير وواضح.
  - قائمة تفصيلية بمصاريف اليوم مع زر حذف وتعديل مباشر.
  - أزرار سريعة بنقرة واحدة (1-Tap) للفئات ذات المبالغ الثابتة (مثال: `+ دخان (5 ₪)`، `+ قهوة (5 ₪)`).
- **⚡ إضافة مصروف بأقل عدد ضغطات**:
  - اختر الفئة -> المبلغ يُملأ تلقائياً -> اضغط تأكيد (نقرة أو نقرتين فقط).
- **🧮 حساب آلي فوري شامل**:
  - حساب تراكمي لمجموع الشهر لغاية اليوم تلقائياً مع كل إدخال.
  - حساب المتبقي من الراتب مباشرة (`الراتب - مصروف الشهر`).
  - تصفير العداد الشهري تلقائياً مع بداية كل شهر جديد.
- **🔮 التوقع الشهري الذكي (Forecast)**:
  - احتساب معدل الصرف اليومي الفعلي.
  - تقدير التكلفة الإجمالية المتوقعة لنهاية الشهر والمتبقي من الراتب.
  - مؤشر تحذيري مبكر: أخضر (آمن)، أصفر (قريب)، أحمر (تجاوز متوقع).
- **📊 رسم بياني يومي مع خط المعدل المسموح**:
  - رسم أعمدة يوضح مصروف كل يوم من بداية الشهر مع خط أفقي يوضح `المعدل اليومي المسموح من الراتب`.
- **📅 سجل الأيام وسجل الحركات**:
  - استعراض الأيام الماضية يوماً بيوم ومصروف كل يوم.
  - سجل زمني كامل لكافة الحركات من الأحدث للأقدم مع البحث.
- **📺 الاشتراكات الشهرية التلقائية**:
  - إدارة اشتراكاتك (نتفليكس، موبايل، إنترنت...).
  - تُخصم وتُسجل تلقائياً في يومها ضمن مصروف اليوم دون تدخل يدوي.
- **🏷️ إدارة الفئات**:
  - إضافة فئات يومية أو شهرية مع تعيين مبلغ افتراضي مسبق.
- **🪙 العملات المدعومة**:
  - الشيكل الفلسطيني (₪ - ILS) كعملة أساسية، مع دعم الدولار ($ - USD).
- **🔒 قفل أمان برقم سري (PIN)**: لحماية خصوصية مصاريفك.
- **💾 تخزين محلي وتصدير كامل (CSV و JSON)**.

## 🚀 التشغيل محلياً

```bash
npm install
npm run dev
```

للتشغيل على الهاتف عبر شبكة الواي فاي:
```bash
npm run dev -- --host
```
